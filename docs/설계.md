# 설계: 개인연금(IRP) 월간 투자 계획 agent

## 1. 요구사항 정리

| 항목 | 내용 |
|---|---|
| 계좌 | IRP 2개: 본인(신한투자증권) 월 40만 원, 남편(우리투자증권) 월 20만 원 |
| 기간 | 30대 후반 → 만 65세 연금 수령(약 27년) |
| 위험 한도 | 최대 손실(MDD) -10% |
| 비중 | 장기 60% : 단기(3개월~1년) 40%, 단기는 계좌 안에서 종목을 바꾸는 방식 |
| 원칙 | 한쪽(미국 지수, 금 등)에 몰리지 않게 분산하고 비중을 조정 |
| 실행 | 매월 자동 실행(c) + 원할 때 수동 실행(a) |
| 데이터 | API 키 없는 공개 데이터 + 최신 뉴스 |
| 출력 | 후보 리스트, 추천 종목, 추천 이유, 초보자용 설명 |
| 기존 적립금 | 본인 IRP 약 1,000만 원은 요청에 따라 계획에서 제외 |

## 2. IRP 제약 (반영 방식)

- **위험자산 70% 한도**: 계좌별로 확인하고, 가격 변동 여유분 3%p를 둬서 67%를 상한으로 씀
- **매수 불가**: 레버리지·인버스, 선물 기반 파생형 ETF → 후보에서 제외(선물형은 과거 데이터 보충용으로만 씀)
- **금**: 선물형 대신 현물형 `ACE KRX금현물` 사용(위험자산으로 분류)
- **채권혼합형**: 주식 40% 미만이면 안전자산(예: TIGER 미국테크TOP10채권혼합)
- 증권사마다 분류가 다를 수 있어 리포트에 "매수 전 앱에서 확인" 안내를 넣음

## 3. 처리 흐름

```
[네이버 금융 시세] ─┐
[FRED 경제지표] ────┼─▶ macro.analyze() ─▶ 경제 국면 + 틸트
[Google News RSS] ──┘                          │
                                               ▼
          core_weights() 장기 바구니 ◀── 기본 비중 + 틸트
          tactical_weights() 단기 바구니 ◀── 모멘텀 + 추세 + 상관 필터
                                               │
                     전체 = 장기×60% + 단기×40%
                                               ▼
          fit_risk(): 과거 5년 시뮬레이션 MDD ≤ -10%, 위험자산 ≤ 67%
                      (넘으면 위험자산을 줄여 현금성·국고채3년으로)
                                               ▼
          buy_plan(): 계좌별·1주 단위 매수 수량(부족분 우선, 월 최대 종목 수)
                                               ▼
          report.render() ─▶ reports/YYYY-MM.md / .json
                                               ▼
          Claude: 최신 뉴스 검색 → 해설 작성 → 커밋·푸시 → 알림
```

## 4. 경제 국면 판단 (macro.py)

| 지표 | FRED 코드 | 의미 |
|---|---|---|
| 장단기 금리차 | T10Y3M | 역전·역전 해소 → 경기 둔화 경계 |
| 실업률·샴 지표 | UNRATE | 0.5%p 이상 → 경기침체 신호 |
| 소비자물가 | CPIAUCSL | 3.5% 이상(또는 3%대 재상승) → 물가 부담 |
| 기준금리 6개월 변화 | FEDFUNDS | 인하 국면이면 채권에 우호적 |
| VIX | VIXCLS | 20↑ 경계, 30↑ 위기 |
| 하이일드 스프레드 | BAMLH0A0HYM2 | 4%p↑ 또는 급등 → 신용 위험 |
| 실질금리 | DFII10 | 하락 → 금에 우호적 |
| 원·달러 | DEXKOUS | 3년 상위 20% → 환노출 자산 일부를 국내로 |

국면별 장기 바구니 조정(%p):

| 국면 | 주식 | 장기채 | 단기채 | 금 | 현금 |
|---|---:|---:|---:|---:|---:|
| 확장·안정 | 0 | 0 | 0 | 0 | 0 |
| 확장 + 물가 부담 | 0 | -5 | +3 | +2 | 0 |
| 경기 둔화 | -5 | +4 | 0 | 0 | +1 |
| 스태그플레이션 경계 | -6 | -5 | +6 | +3 | +2 |
| 위기·고변동 | -10 | 0 | +3 | 0 | +7 |

## 6. 단기 바구니 규칙 (tactical_weights)

1. 점수 = 3·6·12개월 수익률 평균
2. 조건: 점수가 현금성 ETF보다 높고, 현재가가 200일 이동평균 위
3. 통과한 위험자산 중 점수 순으로 최대 3개. 이미 고른 종목과 상관계수 0.85를 넘으면 제외(쏠림 방지)
4. 슬롯당 1/3씩 배정하고, 변동성이 15%를 넘으면 비중을 줄임(예: 변동성 30%면 슬롯의 절반)
5. 남는 몫은 절반을 추세가 좋은 채권에, 나머지는 현금성 ETF에 배정(물가가 높으면 장기채 제외). 조건을 통과한 채권이 없으면 전부 현금성 ETF
6. 위기 국면이면 슬롯을 2개로 줄임

## 7. 한계와 주의

- 과거 MDD는 미래를 보장하지 않습니다. 상장 기간이 짧은 ETF는 비슷한 종목 데이터로 채웠습니다.
- -10% 목표 때문에 주식 비중이 낮게 나올 수 있습니다. 27년이라는 기간을 생각하면 -15%도 검토해 볼 만합니다.
- 모멘텀 전략은 추세가 갑자기 뒤집히는 구간에서 손실이 날 수 있습니다(월 1회 점검의 한계).
- 종목코드와 이름은 실행할 때 자동으로 대조하고, 다르면 추천에서 뺍니다.
